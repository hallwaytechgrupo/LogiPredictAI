# 🚀 LogiPredict AI

Plataforma inteligente de gestão logística e previsão de atrasos no e-commerce desenvolvida como **Projeto Integrador** em colaboração pelos grupos **HallwayTech** & **Octacode** na **FATEC**.

O sistema une técnicas avançadas de Aprendizado de Máquina (*Machine Learning*) utilizando dados reais do varejo brasileiro (Base Olist), uma arquitetura de back-end em Node.js e uma interface moderna multi-plataforma desenvolvida em **Flutter** (Web e Mobile).

## 🗂️ Estrutura do Repositório (Branches)

Este repositório está organizado em branches especializadas para separar os módulos da aplicação:

* **`main`** ➔ Documentação geral, proposta do projeto e visão arquitetural.
* **`back`** ➔ Código-fonte do Back-end (**Node.js**) e Pipeline de Inteligência Artificial / Machine Learning (**Python / Random Forest**).
* **`front`** ➔ Código-fonte da interface de usuário (**Flutter Web & Mobile**).

Para alternar entre os ambientes de código, utilize:
```bash
git checkout back   # Para acessar o código de IA e Back-end
git checkout front  # Para acessar o código em Flutter
